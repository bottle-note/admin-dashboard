# 위스키 엑셀 벌크 등록

화면: `/whisky/excel-bulk`

이 화면은 위스키를 신규 등록합니다. 기존 위스키를 일괄 수정하는 기능이 아닙니다.
최대 1,000개 행을 처리합니다. 이미지 첨부는 선택 사항입니다.

## 순서

1. 양식을 다운로드해 작성합니다. 참고 시트의 코드와 선택값을 사용하세요.
2. `검증할 Excel 파일 선택`에 .xlsx 파일을 선택하고 검증합니다.
3. 검증 결과에서 오류를 해결하고 이미지를 첨부합니다. 경고는 확인 후 진행할 수 있습니다.
4. `최종 전송`에서 건수와 이미지 포함 여부를 검토하고 `등록`을 실행합니다.

## 행 식별과 현재 상태

- 엑셀 행 번호와 위스키명을 함께 사용하세요. 같은 이름의 위스키가 여러 행에 있을 수 있습니다.
- 행별 이미지 버튼 이름은 `3행 글렌피딕 12년 이미지 수정` 형식입니다.
- DOM을 읽는 도구는 표 행의 `data-client-row-id`, `data-row-number`를 사용할 수 있습니다. 행 ID는 현재 검증 결과 안에서 사용합니다.
- `작업 정보`를 펼치면 `현재 벌크 등록 작업 정보 JSON` 읽기 전용 입력에 전체 행 상태가 있습니다. 필터로 가려진 행도 포함됩니다.
- JSON의 `canSubmit`, `blockedReason`, `createdRows`, 행별 `errors`, `warnings`, `imageStatus`, `imageUrl`, `imageError`를 확인하세요.
- `imageStatus`: EMPTY(미첨부), UPLOADING(업로드 중), ERROR(첨부 실패), READY(첨부 완료).
- 업로드 실패 시 `imageUrl`에는 이전에 성공한 이미지가 남을 수 있습니다. URL 존재만으로 새 업로드 성공을 판단하지 마세요.

## 이미지 추가와 수정

- 행별 `추가` 또는 `교체`로 JPG, PNG, WEBP 파일을 선택합니다.
- `수정`은 현재 이미지의 크롭 모듈을 엽니다. 비율, 영역, WebP 품질을 조절하고 `이미지 저장`을 누릅니다.
- `상세 설정 · 크롭 좌표`에서 X, Y, 너비, 높이를 원본 픽셀 단위로 입력하고 `좌표 적용`을 누릅니다. 왼쪽 위가 (0, 0)입니다.
- 고정 비율을 선택했다면 좌표의 너비와 높이도 해당 비율에 맞아야 합니다. 자유 비율에서는 임의 크기를 사용할 수 있습니다.
- `가운데 정렬`은 적용된 영역의 크기를 유지합니다. 자유 비율의 `전체 이미지 선택`은 원본 전체를 선택합니다.
- 좌표 적용은 업로드하지 않습니다. `이미지 저장` 후 행의 첨부 완료 상태까지 기다리세요.
- 취소하면 기존 이미지가 유지됩니다. 업로드 실패 시 재시도하거나 첨부를 취소할 수 있습니다.
- 현재 세션에서 업로드한 이미지는 보관된 파일로 다시 편집합니다. URL로만 불러온 기존 이미지는 서버의 CORS 허용이 필요합니다. 불러오기에 실패하면 원본 파일을 `교체`로 선택하세요.

## 여러 이미지 매칭

1. `여러 이미지 추가`를 엽니다.
2. `파일명 준비`에서 이름을 복사하거나 `파일명 목록 다운로드`로 CSV를 받습니다.
3. 이미지 확장자는 유지하고, 확장자를 제외한 파일명을 안내된 이름과 정확히 맞춥니다. 예: `003_글렌피딕_12년.jpg`.
4. `매칭할 이미지 파일 선택`에 여러 파일을 선택합니다. 드래그도 지원합니다.
5. 대상 없음, 중복, 지원하지 않는 형식은 업로드하지 않습니다. 중복 파일은 하나만 남기세요.
6. 이미 첨부된 행은 `기존 이미지 교체`를 선택해야 덮어씁니다.
7. 매칭 결과를 확인하고 업로드합니다. 실패하면 성공한 파일은 유지되고 실패한 파일만 다시 시도합니다.

파일명 준비부터 매칭 결과까지 전체 모달을 스크롤합니다.
여러 이미지 업로드는 전체 영역을 WebP로 변환합니다. 이후 행별 수정에서 개별 크롭할 수 있습니다.

## 전송과 복구

- 최종 요청의 imageUrl에는 업로드 완료 후 조회 URL(viewUrl)을 사용합니다. 임시 PUT 주소(uploadUrl)를 첨부하지 않습니다.
- 검증 오류, 이미지 업로드 중, 이미지 업로드 실패 상태에서는 전송할 수 없습니다. 비활성화 이유가 전송 버튼 옆에 표시됩니다.
- 등록은 전체 성공 또는 전체 실패입니다. 요청을 반복하면 중복 등록될 수 있어 자동 재시도하지 않습니다.
- 등록 결과가 불명확하면 목록에서 반영 여부를 확인한 뒤 재전송 여부를 결정하세요.
- 성공 후에는 완료 건수가 표시되고 같은 작업의 전송 버튼이 비활성화됩니다.
- 엑셀을 교체하거나 다시 검증하면 이미지 연결이 초기화됩니다. 확인창 내용을 검토하세요.
